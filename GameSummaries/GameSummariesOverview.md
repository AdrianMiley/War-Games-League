#    Game Summaries

This section does not form part of the rules.
The intent is to provide a brief summary of each game registered in the league, including the game type, number of players, typical duration and a brief description of the game.

This is so that people who are looking for some new game to play can get a quick overview of the games that are available in the league and decide which ones they would like to try.
