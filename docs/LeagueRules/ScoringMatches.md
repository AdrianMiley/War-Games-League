#    Match Scoring

1. TOC
   {:toc}

Every completed match contributes points to the league table.

Scoring category

Points

##  Result

| Outcome | Points |
|:--------|:-------|
| Win     | 5      |
| Draw    | 3      |
| Loss    | 1      |

## Participation points

Both players receive 3 points for completing a match, regardless of the result.

## Proficiency handicap bonus

The lower-rated player receives a bonus according to the difference between the players' proficiency ratings for that particular game.
The bonus is awarded regardless of the result.

| Level Difference | Bonus |
|:-----------------|-------|
| 0                | 0     |
| 1                | 0.5   |
| 2                | 1     |
| 3                | 1.5   |
| 4                | 2     |

For example, a Beginner player (Level 2) who plays an Advanced opponent (Level 4) receives 1 additional point i.e. level 4 minus Level 2 is a 2 Level Difference.

## Victory and Defeat Margin Bonus

An additional bonus is awarded for the scale of the result.

| Margin   | Bonus |
|:---------|:------|
| Narrow   | 0     |
| Clear    | 1     |
| Decisive | 2     |

The bonus is awarded to:
-   The winner for a victory.
-   The loser for a defeat.

This means a player who suffers a heavy defeat can still earn additional points.

The organizer should establish appropriate margin thresholds for each game, based on its scoring system and scenario.

Examples include victory point differences, objective scores, casualties or scenario outcomes.

The same thresholds will be applied consistently to all players playing that game and scenario.

## Maximum match score

The maximum normal score for an individual match is 12 points.

| Component     | Maximum |
|:--------------|---------|
| Participation | 3       |
| Result        | 5       |
| Handicap      | 2       |
| Margin bonus  | 2       |
|               |         |
| Total         | 12      |

##  Example

Player A (Beginner) plays Player B (Advanced) and loses decisively.

| Category      | Player A | Player B |
|---------------|----------|----------|
| Participation | 3        | 3        |
| Result        | 1        | 5        |
| Handicap      | 1        | 0        |
| Margin bonus  | 1        | 0        |
|               |          |          |
| Total         | 6        | 8        |

Player A receives 6 points despite losing the game.

This is an important feature of the league: **challenging a stronger opponent should still be rewarding.**
